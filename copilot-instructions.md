
# Instrucciones para GitHub Copilot

## Mensajes de commit

- Todos los mensajes de commit deben estar escritos en español.
- Utilizar un lenguaje claro, profesional y conciso.
- Describir brevemente los cambios realizados.
- Utilizar verbos en presente.
- No generar mensajes de commit en inglés.
- Evitar mensajes genéricos como "actualizaciones" o "cambios".

## Formato

Utilizar Conventional Commits con la siguiente estructura:

tipo: descripción breve del cambio

Tipos permitidos:
- feat: nueva funcionalidad.
- fix: corrección de errores.
- docs: cambios en documentación.
- style: cambios de formato o estilos.
- refactor: mejoras en el código.
- test: incorporación o modificación de pruebas.
- chore: tareas de mantenimiento.

## Ejemplos

- docs: actualizar el README del repositorio
- feat: agregar ejercicios de React
- feat: implementar componente de navegación
- fix: corregir validación de datos
- refactor: mejorar estructura del código
- test: agregar pruebas unitarias
